# کلاس — Android V3

نسخه V3 بر پایه مستقیم پروژه V2 ساخته شده، اما معماری آن از نگهداری داده در RAM به **Room/SQLite** منتقل شده است.

## اصلاحات کلیدی
- حذف Apache POI از Android؛ ورود XLSX با parser داخلی ZIP/XML.
- رفع خطای Kotlin `?:` در ورود Excel.
- ذخیره دائمی زبان‌آموزان، اساتید، دوره‌ها، کلاس‌ها و گزارش روزانه.
- شناسه‌های یکتا به جای `size+1`.
- جستجوی زبان‌آموز با کد، نام، نام خانوادگی، موبایل و کد ملی.
- گزارش هفتگی/ماهانه با فیلتر بازه تاریخ `yyyy/MM/dd`.
- پشتیبان‌گیری JSON.
- GitHub Actions با Java 17 و Android SDK.

## وضعیت V3
این بسته **هسته واقعی و قابل توسعه V3** است. ثبت‌نام، حضور و غیاب، شهریه/پرداخت، نمرات/کارنامه، کارت و بارکد در مدل معماری پیش‌بینی شده‌اند و مرحله بعد باید UI کامل آنها تکمیل شود.
